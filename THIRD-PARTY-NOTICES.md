# Third-party data

`HarborBrowser/PublicSuffixList.dat` is the Public Suffix List distributed by the [Public Suffix List project](https://publicsuffix.org/list/). It is licensed under the [Mozilla Public License 2.0](https://mozilla.org/MPL/2.0/). The original license notice and version metadata remain in the bundled source file. Harbor uses the list to keep site-data deletion within the current registrable domain, including private suffixes such as `github.io`. Lists refresh when source is updated, not automatically on the device.

AdGuard filter sources and conversion attribution are recorded in the generated `HarborBrowser/Filters` reports and the **Harbor-filter-sources-and-report** GitHub build artifact. See that report for each list's source and license.

Harbor's sailboat app icon is original project artwork; it does not use Brave trademarks or assets.
